# Практична робота: Пошук спільних простих дільників

**Завдання:** Знайти всі спільні прості дільники двох заданих тризначних чисел.

### Опис рішення:
1. Програма приймає два цілих числа.
2. Проводиться цикл від 2 до найменшого з чисел.
3. Кожне число перевіряється на:
   - Чи є воно дільником обох заданих чисел без залишку.
   - Чи є воно простим (ділиться тільки на 1 та на самого себе).
4. Результат повертається у вигляді рядка, де числа розділені комою.

**Приклад роботи:**
Для чисел `120` та `180` спільними простими дільниками будуть: `2, 3, 5`.
